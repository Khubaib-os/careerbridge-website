# CareerBridge — 27-page React/Vite website source

Run `npm install` then `npm run dev`. Build with `npm run build`.

## Included
- Original cinematic homepage and original company page layouts
- 27 route components (home, five company, seven services, five solutions, three trust, three support, three legal)
- Shared `SiteNav` with Who We Are, Services and Solutions dropdowns; desktop mouse-leave closing, outside click, Escape and mobile toggle
- Shared footer and content layout; distinct copy for each page
- Desktop 90% content containers; mobile responsive rules
- Homepage intro waits for scroll after automatic globe and brand reveal (wheel, touch, keyboard, or Enter Website button)

## Before publishing
- Replace placeholder team profiles and provide verified case studies/testimonials
- Configure a real email/contact endpoint, quote form and booking calendar. Demo forms DO NOT submit to a server.
- Review all legal drafts with a qualified professional, inserting the actual entity, location, data practices, terms, retention periods and dates.
- Check licensing and availability of externally hosted Unsplash photographs; ideally self-host approved assets.
- Run desktop/mobile browser QA, accessibility testing and build checks.
- No employment or interview outcomes are guaranteed.
